# Fitness Tracker API

A simple fitness tracking web application built with ASP.NET Core that allows users to log workouts, track exercises, sets, reps, and weight, and monitor their progress over time.

This is a personal pet project created to practice backend development with ASP.NET Core, Entity Framework Core, and clean architecture principles.

## Features

* User registration and authentication
* Manual workout logging (exercises, sets, reps, weight)
* Workout history and progress tracking
* Basic calculations (e.g. total volume, personal records)

## Tech Stack

* **Backend:** ASP.NET Core Web API
* **Database:** Microsoft SQL Server
* **ORM:** Entity Framework Core
* **Auth:** ASP.NET Core Identity
